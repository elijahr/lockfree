<p>src/lockfree/chronos.nim</p>
<p>Tier 3 chronos async adapter for <tt class="docutils literal"><span class="pre"><span class="Identifier">lockfree</span></span></tt> queues. This is the only async tier shipping in v0.1.0, built on the hybrid optional-dep pattern.</p>
<p>chronos is intentionally NOT listed unconditionally in <tt class="docutils literal"><span class="pre"><span class="Identifier">lockfree</span><span class="Operator">.</span><span class="Identifier">nimble</span></span></tt> <tt class="docutils literal"><span class="pre"><span class="Identifier">requires</span></span></tt>. The library is flag-only opt-in: users who want the async adapter pass <tt class="docutils literal"><span class="pre"><span class="Operator">-</span><span class="Identifier">d</span><span class="Punctuation">:</span><span class="Identifier">lockfreeChronos</span></span></tt> AND install chronos themselves (or rely on <tt class="docutils literal"><span class="pre"><span class="Identifier">lockfree</span><span class="Operator">.</span><span class="Identifier">nimble</span></span></tt>'s <tt class="docutils literal"><span class="pre"><span class="Keyword">when</span> <span class="Identifier">defined</span><span class="Punctuation">(</span><span class="Identifier">lockfreeChronos</span><span class="Punctuation">)</span><span class="Punctuation">:</span> <span class="Identifier">requires</span> <span class="StringLit">&quot;chronos &gt;= 4.0.0, &lt; 5.0.0&quot;</span></span></tt> conditional dep). The library never transitively pulls chronos in for users who do not need it, and chronos is never auto-detected at compile time.</p>
<p>Activation matrix (flag-only opt-in):</p>
<p><tt class="docutils literal"><span class="pre"><span class="Operator">-</span><span class="Identifier">d</span><span class="Punctuation">:</span><span class="Identifier">lockfreeChronos</span></span></tt> | chronos installed | outcome -------------------- | ----------------- | ----------------------------- No | (irrelevant) | (d) import succeeds; module body skipped; AsyncQueue/ AsyncBQueue invisible. Yes | Yes | (b) opt-in path; module body activates; types exported. Yes | No | (c) <tt class="docutils literal"><span class="pre"><span class="Punctuation">{</span><span class="Operator">.</span><span class="Identifier">error</span><span class="Operator">.</span><span class="Punctuation">}</span></span></tt> fires with a precise install hint referencing <tt class="docutils literal"><span class="pre"><span class="Identifier">docs</span><span class="Operator">/</span><span class="Identifier">api</span><span class="Operator">/</span><span class="Identifier">chronos</span><span class="Operator">.</span><span class="Identifier">md</span></span></tt>.</p>
<p>The previous auto-detect arm — a public <tt class="docutils literal"><span class="pre"><span class="Identifier">lockfreeChronosAvailable</span><span class="Operator">*</span></span></tt> constant that callers could <tt class="docutils literal"><span class="pre"><span class="Keyword">when</span></span></tt>-branch on to silently enable the adapter without the flag — was removed: silent activation based on whether chronos happens to be installed in a user's package set violates the flag-only opt-in contract. An internal (non-exported) <tt class="docutils literal"><span class="pre"><span class="Identifier">chronosReachable</span></span></tt> probe is retained ONLY to drive the precise install-hint <tt class="docutils literal"><span class="pre"><span class="Punctuation">{</span><span class="Operator">.</span><span class="Identifier">error</span><span class="Operator">.</span><span class="Punctuation">}</span></span></tt> arm; the module body never activates without <tt class="docutils literal"><span class="pre"><span class="Operator">-</span><span class="Identifier">d</span><span class="Punctuation">:</span><span class="Identifier">lockfreeChronos</span></span></tt>, regardless of whether chronos is reachable.</p>
<p>NOTE on chronos import form: the obvious <tt class="docutils literal"><span class="pre"><span class="Keyword">import</span> <span class="Identifier">chronos</span></span></tt> self-shadows inside this module — our own file IS <tt class="docutils literal"><span class="pre"><span class="Identifier">src</span><span class="Operator">/</span><span class="Identifier">lockfree</span><span class="Operator">/</span><span class="Identifier">chronos</span><span class="Operator">.</span><span class="Identifier">nim</span></span></tt>, which Nim resolves first on the import search path, breaking the <tt class="docutils literal"><span class="pre"><span class="Identifier">compiles</span> <span class="Keyword">do</span><span class="Punctuation">:</span></span></tt> probe used to emit the precise install-hint error. We import the chronos <em>submodule</em> <tt class="docutils literal"><span class="pre"><span class="Identifier">chronos</span><span class="Operator">/</span><span class="Identifier">asyncsync</span></span></tt> (which transitively re-exports asyncloop -&gt; asyncfutures + asyncmacro, covering AsyncEvent, Future, async/await, waitFor, CancelledError) and we use the bracket-array form <tt class="docutils literal"><span class="pre"><span class="Identifier">chronos</span><span class="Operator">/</span><span class="Punctuation">[</span><span class="Identifier">asyncsync</span><span class="Punctuation">]</span></span></tt>. The bracket form is what makes the resolver locate the chronos package despite the local module's name. A leading throw-away <tt class="docutils literal"><span class="pre"><span class="Identifier">compiles</span> <span class="Keyword">do</span><span class="Punctuation">:</span> <span class="Keyword">import</span> <span class="Identifier">chronos</span><span class="Operator">/</span><span class="Identifier">asyncsync</span></span></tt> primes Nim's package resolver so the bracket form binds correctly on the next call — without that prime the bracket form returns false on the very first invocation in a module whose own name is &quot;chronos&quot;. This priming probe is deliberate and is required to defeat the self-shadowing; it is NOT an auto-detect arm, and its result is discarded.</p>
