Bridge <tt class="docutils literal"><span class="pre"><span class="Keyword">ref</span></span></tt> types into <tt class="docutils literal"><span class="pre"><span class="Identifier">Atomic</span><span class="Punctuation">[</span><span class="Keyword">ptr</span> <span class="Identifier">T</span><span class="Punctuation">]</span></span></tt> storage with explicit GC tracking.
<h2><a class="toc-backref" id="why" href="#why">Why</a></h2><p><tt class="docutils literal"><span class="pre"><span class="Identifier">Atomic</span><span class="Punctuation">[</span><span class="Keyword">ref</span> <span class="Identifier">T</span><span class="Punctuation">]</span></span></tt> falls back to spinlock-based atomics on arc/orc, which defeats lock-free guarantees. For atomic pointer storage in lock-free data structures, convert the <tt class="docutils literal"><span class="pre"><span class="Keyword">ref</span></span></tt> into a raw <tt class="docutils literal"><span class="pre"><span class="Keyword">ptr</span> <span class="Identifier">T</span></span></tt>, increment the GC ref count manually so the object survives, and decrement it from the DEBRA destructor at retire-reclaim time.</p>

<h2><a class="toc-backref" id="api" href="#api">API</a></h2><ul class="simple"><li><tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span><span class="Punctuation">(</span><span class="Identifier">obj</span><span class="Punctuation">)</span></span></tt> -&gt; <tt class="docutils literal"><span class="pre"><span class="Keyword">ptr</span> <span class="Identifier">T</span></span></tt>: GC_ref + cast.</li>
<li><tt class="docutils literal"><span class="pre"><span class="Identifier">release</span><span class="Punctuation">(</span><span class="Identifier">p</span><span class="Punctuation">)</span></span></tt>: GC_unref the pointer (nil-safe).</li>
<li><tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt> -&gt; <tt class="docutils literal"><span class="pre"><span class="Identifier">Destructor</span></span></tt>: factory that returns a <tt class="docutils literal"><span class="pre"><span class="Identifier">Destructor</span></span></tt> releasing a <tt class="docutils literal"><span class="pre"><span class="Keyword">ptr</span> <span class="Identifier">T</span></span></tt>. Pass to <tt class="docutils literal"><span class="pre"><span class="Identifier">it</span><span class="Operator">.</span><span class="Identifier">retire</span><span class="Punctuation">(</span><span class="Identifier">p</span><span class="Punctuation">,</span> <span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span><span class="Punctuation">)</span></span></tt>.</li>
</ul>
<p>Each <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> MUST be paired with exactly one <tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt> (typically via <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt> handed to <tt class="docutils literal"><span class="pre"><span class="Identifier">pin</span><span class="Operator">.</span><span class="Identifier">retire</span></span></tt>). Double-release will free the underlying object early.</p>

<h2><a class="toc-backref" id="pitfalls" href="#pitfalls">Pitfalls</a></h2><ul class="simple"><li>Every <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> must be paired with exactly one <tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt>. Double-release will free the object early; missing release leaks the underlying GC cell.</li>
<li><tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt> is nil-safe (no-op on <tt class="docutils literal"><span class="pre"><span class="Keyword">nil</span></span></tt>). Passing <tt class="docutils literal"><span class="pre"><span class="Keyword">nil</span></span></tt> to <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> is a programmer error and will likely crash inside <tt class="docutils literal"><span class="pre"><span class="Identifier">GC_ref</span></span></tt>.</li>
<li>Under <tt class="docutils literal"><span class="pre"><span class="Operator">--</span><span class="Identifier">mm</span><span class="Punctuation">:</span><span class="Identifier">refc</span></span></tt>, <tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt> (or any reclamation that runs the destructor produced by <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt>) must occur on the same thread that called <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt>. refc has thread-local GC heaps; cross-thread <tt class="docutils literal"><span class="pre"><span class="Identifier">GC_unref</span></span></tt> is undefined and crashes inside <tt class="docutils literal"><span class="pre"><span class="Identifier">decRef</span></span></tt>. arc/orc use atomic shared refcounts and are not affected. See <tt class="docutils literal"><span class="pre"><span class="Identifier">examples</span><span class="Operator">/</span><span class="Identifier">reclamation_background</span><span class="Operator">.</span><span class="Identifier">nim</span></span></tt> for the full investigation.</li>
</ul>

<h2><a class="toc-backref" id="naming-convention" href="#naming-convention">Naming convention</a></h2><p>This module is the <strong>object-lifetime</strong> layer: <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> / <tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt> / <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span></span></tt> operate on a single object's GC refcount and have no awareness of epochs, threads, or limbo bags.</p>
<p>The <strong>manager-level</strong> layer in <tt class="docutils literal"><span class="pre"><span class="Identifier">debra</span><span class="Operator">/</span><span class="Identifier">convenience</span></span></tt> and <tt class="docutils literal"><span class="pre"><span class="Identifier">debra</span><span class="Operator">/</span><span class="Identifier">typestates</span><span class="Operator">/</span><span class="Punctuation">{</span><span class="Identifier">retire</span><span class="Punctuation">,</span><span class="Identifier">reclaim</span><span class="Punctuation">}</span></span></tt> uses different verbs (<tt class="docutils literal"><span class="pre"><span class="Identifier">retire</span></span></tt>, <tt class="docutils literal"><span class="pre"><span class="Identifier">reclaim</span></span></tt>, <tt class="docutils literal"><span class="pre"><span class="Identifier">tryReclaim</span></span></tt>, <tt class="docutils literal"><span class="pre"><span class="Identifier">retireAndReclaim</span></span></tt>) because it operates on the epoch-based reclamation pipeline: deferring destruction until no thread can observe the object. The two layers compose: a <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt> value is the destructor handed to <tt class="docutils literal"><span class="pre"><span class="Identifier">pin</span><span class="Operator">.</span><span class="Identifier">retire</span><span class="Punctuation">(</span><span class="Identifier">p</span><span class="Punctuation">,</span> <span class="Identifier">dtor</span><span class="Punctuation">)</span></span></tt> so that <tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt> runs at safe-epoch reclamation time. The verbs differ because the layers differ; do not expect <tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt> and <tt class="docutils literal"><span class="pre"><span class="Identifier">reclaim</span></span></tt> (or <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> and <tt class="docutils literal"><span class="pre"><span class="Identifier">retire</span></span></tt>) to be synonyms.</p>

## Procedures & Functions

### `retain`

```nim
proc retain[T: ref](obj: T): ptr typeof(obj[]) {.inline.}
```

<p>Increment the GC ref count and return a raw pointer suitable for atomic storage. The caller owns the resulting pointer's reference count; pair every <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> with exactly one <tt class="docutils literal"><span class="pre"><span class="Identifier">release</span></span></tt> (usually via <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt> handed to <tt class="docutils literal"><span class="pre"><span class="Identifier">pin</span><span class="Operator">.</span><span class="Identifier">retire</span></span></tt>).</p>
<p>Passing nil is a programmer error and will likely crash inside <tt class="docutils literal"><span class="pre"><span class="Identifier">GC_ref</span></span></tt>. The result is never nil.</p>
<p>See also: <a class="reference internal" href="#release">release</a>, <a class="reference internal" href="#releaseDestructor">releaseDestructor</a>.</p>

### `release`

```nim
proc release[T](p: ptr T) {.inline.}
```

<p>Decrement the GC ref count for a pointer obtained via <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt>. Safe to call on <tt class="docutils literal"><span class="pre"><span class="Keyword">nil</span></span></tt> (no-op).</p>
<p>Note: takes <tt class="docutils literal"><span class="pre"><span class="Keyword">ptr</span> <span class="Identifier">T</span></span></tt> (the value type), matching what <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> returns.</p>
<p>See also: <a class="reference internal" href="#retain">retain</a>, <a class="reference internal" href="#releaseDestructor">releaseDestructor</a>.</p>

### `releaseDestructor`

```nim
proc releaseDestructor[T](): Destructor {.inline.}
```

<p>Return the <tt class="docutils literal"><span class="pre"><span class="Identifier">Destructor</span></span></tt> (the type DEBRA's <tt class="docutils literal"><span class="pre"><span class="Identifier">retire</span></span></tt> accepts) that releases a typed pointer obtained from <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span><span class="Punctuation">[</span><span class="Keyword">ref</span> <span class="Identifier">T</span><span class="Punctuation">]</span></span></tt>. Hand the result to <tt class="docutils literal"><span class="pre"><span class="Identifier">pin</span><span class="Operator">.</span><span class="Identifier">retire</span><span class="Punctuation">(</span><span class="Identifier">rawPtr</span><span class="Punctuation">,</span> <span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span><span class="Punctuation">)</span></span></tt>.</p>
<p><tt class="docutils literal"><span class="pre"><span class="Identifier">T</span></span></tt> may be supplied as either the object type or its <tt class="docutils literal"><span class="pre"><span class="Keyword">ref</span></span></tt> alias — <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">NodeObj</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt> and <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">Node</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt> (where <tt class="docutils literal"><span class="pre"><span class="Identifier">Node</span> <span class="Operator">=</span> <span class="Keyword">ref</span> <span class="Identifier">NodeObj</span></span></tt>) both produce a destructor that decrements the correct GC cell. The implementation branches on <tt class="docutils literal"><span class="pre"><span class="Identifier">T</span> <span class="Keyword">is</span> <span class="Keyword">ref</span></span></tt> to avoid a silent <tt class="docutils literal"><span class="pre"><span class="Keyword">cast</span><span class="Punctuation">[</span><span class="Keyword">ref</span> <span class="Keyword">ref</span> <span class="Identifier">T</span><span class="Punctuation">]</span></span></tt> on the alias spelling. The object-type spelling is canonical (it matches what <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span></span></tt> returns: <tt class="docutils literal"><span class="pre"><span class="Keyword">ptr</span> <span class="Identifier">typeof</span><span class="Punctuation">(</span><span class="Identifier">obj</span><span class="Punctuation">[</span><span class="Punctuation">]</span><span class="Punctuation">)</span></span></tt>); the alias spelling exists for symmetry with <tt class="docutils literal"><span class="pre"><span class="Identifier">retain</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">:</span> <span class="Keyword">ref</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Identifier">obj</span><span class="Punctuation">:</span> <span class="Identifier">T</span><span class="Punctuation">)</span></span></tt>.</p>
<p>The returned <tt class="docutils literal"><span class="pre"><span class="Identifier">Destructor</span></span></tt> is a plain <tt class="docutils literal"><span class="pre"><span class="Identifier">nimcall</span></span></tt> procedure address with no captured environment, so each <tt class="docutils literal"><span class="pre"><span class="Identifier">T</span></span></tt> instantiation produces one function pointer that is reused across calls. Calling <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">T</span><span class="Punctuation">]</span><span class="Punctuation">(</span><span class="Punctuation">)</span></span></tt> repeatedly does not allocate. Note that <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">NodeObj</span><span class="Punctuation">]</span></span></tt> and <tt class="docutils literal"><span class="pre"><span class="Identifier">releaseDestructor</span><span class="Punctuation">[</span><span class="Identifier">Node</span><span class="Punctuation">]</span></span></tt> instantiate to <em>different</em> function pointers — same behaviour, two entries in the binary. Pick one form per call site.</p>
<p>See also: <a class="reference internal" href="#retain">retain</a>, <a class="reference internal" href="#release">release</a>.</p>
