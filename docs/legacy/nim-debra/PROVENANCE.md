# nim-debra docs provenance

These docs are preserved from the upstream `elijahr/nim-debra` repo at
the T0 merge point (commit `ff63ebd`, 2026-06-05) when nim-debra was
consolidated into the lockfree umbrella.

They are kept verbatim as a historical reference for the DEBRA / NEBR
SMR scheme as it appeared at the umbrella consolidation point. They are
NOT the live, supported docs for SMR in lockfree.

- **Live SMR docs**: see [`../../guide/smr/nebr.md`](../../guide/smr/nebr.md)
  for the v0.1.0 renamed content (DEBRA → nebr) with the R6 Brown 2015
  attribution correction.
- **Provenance + deviations from Brown 2015**: tracked in the working
  substrate (`docs/internal/debra-plus-provenance.md`). That substrate
  is gitignored per the 2026-06-07 documentation policy — refer to it
  from a local checkout if needed.
