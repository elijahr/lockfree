    StreamBuffer (Byte Streaming Ring Buffer)¶

    lockfree/streambuffer implements a high-performance, lock-free byte streaming ring buffer for contiguous binary streams, network packets, and audio/video pipelines.

    Overview¶

    • Core Type: StreamBuffer
    • Operations:
    • write(data, len): Write byte sequences atomically or in contiguous chunks.
    • read(buffer, len): Read byte sequences out of the buffer.
    • peek(buffer, len): Inspect bytes without advancing consumer read pointer.
    • Progress Guarantee: Wait-free SPSC; lock-free MPMC.

    Example¶

    import lockfree

var stream = newStreamBuffer(capacity = 4096)

let data = "Hello, lockfree streaming!"
let written = stream.write(data[0].unsafeAddr, data.len)

var buf = newString(data.len)
let readBytes = stream.read(buf[0].addr, buf.len)
assert buf == data

    Concurrency Topology & Mathematical Model: | Dimension | Architectural Specification | |:------------------------|:-------------------------------------------------------------------------| | Primary Topology | SPSC (Single-Producer Single-Consumer) Streaming Byte Ring | | Multi-Thread Modes | SPSC (Wait-Free) & MPMC (Ticket-Reservation Two-Phase Commit) | | Cursor Architecture | 64-bit Monotonic Sequence Numbers (head, tail) with Mask Indexing | | Memory Isolation | Cursors Isolated on Independent Cachelines (align: CacheLineBytes) | | Zero-Copy Substrate | Dual-Slice Vector Model (IOVecPair) & Mirrored Virtual Memory Mapping | | I/O Subsystem | Native Integration with POSIX readv/writev (struct iovec) / Sockets| | Backpressure Engine | Speculative Lock-Free Fast Path + OS Futex Wait-Free Coordination | | Memory Model | Strict C11 Acquire/Release Fence Discipline (moAcquire, moRelease) | | Allocation Cost | Page-Aligned Buffer Allocation (posix_memalign, _aligned_malloc) | ==============================================================================
